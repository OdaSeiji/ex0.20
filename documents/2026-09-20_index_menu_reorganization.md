# index.html メニュー整理(2026-09-20)

- 作成日: 2026-09-20
- 対象システム: ex0.20 (`C:\xampp\htdocs\ex0.20`)
- ステータス: 完了・動作確認済み

## 背景

トップメニュー(`index.html`)のセクション構成・アイコン・並びを整理した。件数が増えて見つけにくくなってきたための整理と、アイコンの意味不一致(スタッフ管理にレンチアイコン等)の解消が目的。

## 変更内容

### 1. 「各種設定」セクションの再編

- 元は2段構成(1段目2項目、2段目5項目でカード幅が不揃い)だったのを、4段に再編
  - 1段目: 金型進捗一覧、金型輸入固定資産登録
  - 2段目: 品番管理、金型管理、図面管理(3項目)
  - 3段目: 金型－品番 紐づけ
  - 4段目: スタッフ管理
- 「金型登録・管理」→「金型管理」、「型材図面」→「図面管理」、「スタッフ設定」→「スタッフ管理」に改名(ja/vi両方)
- CSS: `.menu-row`は元々`grid-template-columns: repeat(auto-fit, minmax(250px, 1fr))`で、項目数が少ない行のカードが不自然に横広がりしていた。各種設定セクションの行にだけ`.fixed3`クラスを追加し、`grid-template-columns: repeat(3, 1fr)`で3列固定にすることで、3つ未満の行はストレッチさせず左詰めで統一幅にした(他セクションの`.menu-row`には影響しない、各種設定専用のクラス)

### 2. セクション見出し「新規、金型、品番登録」→「🚢 金型輸出、部品輸出」に改名

絵文字を📋→🚢(船)に変更。ユーザー選定。

### 3. 各種設定のアイコンを新規作成・整理

元々メニュー全体で使い回されていたアイコンは`factory.svg`・`wrench.svg`・`chart.svg`・`warning.svg`・`handover.svg`の5種類のみで、意味が合っていないものもあった(スタッフ管理にwrench等)。新たに4種類のSVGアイコンを追加(`img/`配下、既存アイコンと同じ単色24x24スタイル):

- `table.svg`(表アイコン) → 金型進捗一覧
- `register.svg`(登録アイコン、ドキュメント+プラス) → 金型輸入固定資産登録
- `link.svg`(リンクアイコン) → 金型－品番 紐づけ
- `person.svg`(人物アイコン) → スタッフ管理

品番管理・金型管理・図面管理の3つは同じ`chart.svg`に統一。

### 4. 「金型輸出・輸入・固定資産登録」→「金型輸入固定資産登録」に改名

「輸出」の実態が無いため名称から削除。

### 5. 「プレス指示作成」を「生産管理」→「押出工程」セクションに移動

`press_directive.html`へのリンク。移動と合わせて、タイトルから「（試作）」を外し(2026-09-20実施のフェーズ1・フェーズ2で完成したため)、説明文も現状の機能(オーダーシート連携ではなく、金型選択→過去の指示参考→押出条件作成・保存・印刷)に合わせて更新。ja/vi両方。
