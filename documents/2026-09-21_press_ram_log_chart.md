# 2026-09-21 押出中 ラムログ グラフページの新設（試作）

## 目的
新設した`t_press_ram_log`テーブル（押出中のラム圧力・速度・位置・出口温度のPLCサンプリングデータ）を
可視化し、ビレットごとの押出状態を確認しやすくするため。

## 内容

### t_press_ram_log テーブル
押出中に一定間隔でサンプリングされるPLC値を記録。

| Field | 内容 |
|---|---|
| machine | 号機 |
| billet_counter | ビレットカウンター |
| die_name | 型番 |
| date_time | 記録日時 |
| ram_position | ラム位置（生値、mm） |
| ram_speed | ラム速度（生値、1/10でmm/s） |
| ram_pressure | ラム圧力（生値、1/10でMPa） |
| exit_temp | 出口温度（生値、1/1で℃） |

### 新規ページ: press_ram_log_chart.html
- 日付 → 型番（号機付き） → ビレット本数、の3段階プルダウンで対象データを選択。
- Chart.jsによる折れ線グラフ。横軸はラム位置（1200mm ← → 0mm、固定レンジ、左が1200・右が0）。
- 縦軸は3軸（左：ラム圧力、右：出口温度、右：ラム速度）で固定レンジ表示。
  - ラム圧力：0〜30 MPa（PLC生値の1/10）
  - ラム速度：0〜8 mm/s（PLC生値の1/10）
  - 出口温度：400〜600 ℃（PLC生値そのまま）
- グラフ幅は画面サイズに関わらず一定になるよう`chart-wrap`に`max-width`を設定。
- グラフ上部に、ラム位置900/500/200mm時点（最も近い実測点）の圧力・速度・温度を表で表示。
- 現在表示中のビレットデータをCSV出力するボタンを追加（単位変換済み、BOM付きでExcel対応）。
- 日本語／ベトナム語の多言語対応（他ページと同様の`dict{ja,vi}`+`data-key`方式）。
- 他の実績レポートページと同様の「← 戻る」ボタンを追加（index.htmlへ遷移）。

### 新規API: php/press_ram_log/ram_log_api.php
`mode`パラメータで以下を切り替えるシンプルなJSON API。
- `dates`：記録のある日付一覧
- `dies`：指定日の型番・号機一覧
- `billets`：指定日・型番のビレット本数一覧
- `log`：指定日・型番・ビレット本数のラムログ本体（時系列）

### index.html
- 「📈 実績レポート」セクションの見出しを「📈 実績」に短縮。
- 同セクションに「（試作）ラムログ グラフ」カードを追加し、press_ram_log_chart.htmlへ遷移できるようにした。

### whats_new.html
- 本更新内容を新規エントリとして追加（日本語／ベトナム語）。
