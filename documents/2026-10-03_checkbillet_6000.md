# 2026-10-03 ビレット棚卸し：9インチ VN の長さ 6000mm を追加

## 目的

ビレット棚卸し（exd11 CheckBilletV4 → ex0.20 へ移植予定）に、長さ 6000mm を追加する。
6000mm は **9インチの VN ビレットだけ**にあり、材質は 6061・6063・6N01A の3つ（ユーザー確認、2026-10-03）。

## 方針

`t_checkbillet` は「材質×太さ×長さ×VN」を列名に持つ横長のテーブルで、設計に問題がある
（列名の「228」は9インチの直径なのに14インチの行でも同じ列を使う、種類が増えるたびに列が増える、など）。

新しいテーブル（ビレットの種類のマスタ＋棚卸しの明細）にする案も検討したが、
ex0.11 の生産計画・梱包計画がこのテーブルを読んでおり、現場の ex0.20 への移行には3か月ほどかかる見込みのため、
**当面は `t_checkbillet` をそのまま使い、列を足す**（ユーザー判断）。
テーブルの再設計は、現場が ex0.20 に完全に移行したあとに行う。

## DB変更

| SQL | ローカル | 本番 |
|---|---|---|
| `t_checkbillet` に 6000mm VN の列を3つ追加 | 実行済み（2026-10-03） | 実行済み（2026-10-03） |

列名は今の決まり（`A`＋材質＋`228`＋長さ＋`_vn`）に合わせた。

```sql
ALTER TABLE t_checkbillet
  ADD COLUMN A60612286000_vn  INT(11) NULL DEFAULT NULL AFTER A6N01A2281200_vn,
  ADD COLUMN A60632286000_vn  INT(11) NULL DEFAULT NULL AFTER A60612286000_vn,
  ADD COLUMN A6N01A2286000_vn INT(11) NULL DEFAULT NULL AFTER A60632286000_vn;
```

確認用：
```sql
SHOW COLUMNS FROM t_checkbillet LIKE '%6000%';   -- 3列
```

ex0.11 の CheckBilletV4 の保存（InsCheckBilletV4.php）は列名を指定して INSERT しているので、列を足しても動く（新しい列は NULL になる）。
ローカルで ex0.11 の一覧（SelSummaryV4.php）が今までどおり返ることを確認した。
6000mm は ex0.11 の画面からは入力できない。ex0.20 版の棚卸し画面で入力する。
