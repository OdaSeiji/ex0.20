## 5. 覚えておくと役に立つこと

- 一覧が遅いときは「表示する id を先に決めてから集計する」（品質集計で約9秒→0.15秒）
- 同じ時刻の押出は並び順が決まらないので、並びの最後に `t_press.id DESC` を付ける
- MariaDB の split_materialized（LATERAL DERIVED）で SQL が終わらないことがある。`SET SESSION optimizer_switch='split_materialized=off'`
- ブラウザでの確認は、JS でイベントを起こして確かめるほうが確実。ダイアログ（confirm・印刷）は自動では押さない
- Excel の取り込みは、ブラウザで `lib/xlsx.js` を使って CSV に変えて送る（PHP は CSV のまま）
- 持ち時間（シフト）は、週に1行も無ければ前の週を引き継いで読む（php/operation_time/common.php）。稼働日報とスケジュール表も同じ
- MySQL が起動しないときの直し方はメモリ（Aria のログを退避）にある
