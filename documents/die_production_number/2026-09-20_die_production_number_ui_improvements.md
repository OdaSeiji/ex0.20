# die_production_number.html UI改善

- 作成日: 2026-09-20
- 対象システム: ex0.20 (`C:\xampp\htdocs\ex0.20`)
- ステータス: 完了・動作確認済み

## 背景

前日(2026-09-19)新設した`die_production_number.html`(金型⇔品番の紐づけ画面)について、実際に使ってみてのフィードバックを反映した。

## 変更内容

1. **タイトル変更**: 「金型×品番 登録」→「金型－品番 紐づけ」(index.htmlのメニュー表記も統一)
2. **Step2(この金型が作れる品番)を初期表示**: 以前は金型未選択時は非表示だったが、「先に金型を選択してください」の空メッセージ付きで常時表示するよう変更
3. **「全体一覧」→「登録金型一覧」に改名**
4. **絞り込み欄(型番検索)を強調**: 幅220px・太字・青枠・薄黄色背景に
5. **ハイフン2つ以上の金型のみ表示するチェックボックスを追加**: `-ZZZ`・`-20K`等の複製金型を素早く抽出できるように(`(die_number.match(/-/g)||[]).length >= 2`で判定)
6. **品番の自動サジェスト候補を先頭5文字→7文字に変更**(`php/die_production_number/search_production_numbers.php`)
7. **金型検索入力に`autocomplete="off"`を追加**: ブラウザの入力補完候補が出ないように

## 動作確認

Chrome操作で全項目を実機確認済み(2026-09-20)。ハイフンフィルタ・7文字サジェスト・タイトルバーの見た目変更など、いずれもスクリーンショットで確認済み。
